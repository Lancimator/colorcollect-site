How to use it

  1. Pick who is playing. Little kids get only bold, unmistakable colors. Kids get a mix of easy and medium ones. Teens and adults get the in-between hues nobody agrees on.
  2. Pick how many colors. Six is a ten-minute hunt for small children; twelve is a proper afternoon for a group of adults.
  3. Generate until you like it. Every click draws a fresh set of colors and a fresh "where to look" hint for each one. Turn the hints off for a harder hunt.
  4. Print and go. The print button prints just the sheet — no website around it. Print one per player or one per team.

Frequently asked questions

How does the color scavenger hunt generator work?

Choose who is playing and how many colors you want, then press Generate. It picks that many colors at the right difficulty, adds a real-world hint for each, and lays them out as a printable checklist with a swatch, a tick box and a line to write the find.

Is the generator free?

Yes. There is no signup and nothing to download — generate as many lists as you like and print them straight from the page.

Will two players get the same list?

Only if you print one list for everyone. Press Generate once per player and each gets a different set of colors, which stops copying.

Can I use it in a classroom?

Yes. A different sheet per table keeps groups from following each other around, and the little-kids preset uses only colors young children can name.
